## 功能

- **错题次数记录**：每道错题累计答错次数（≥3 次标红）、可按「错得最多」排序，
  答对后次数留底；一场会话同一题只计一次，交卷不双计。
- **错题本按题型重练**：- **错题本按题型重练**：错题本顶部四张卡（单选/多选/判断/全部题型）分开练，组内最早错的排前；
  混合重练时答题卡按题型分段、可随时跳段，已答不丢。
- **夜间模式**：右上角 🌙/☀️ 一键切换纯黑 OLED 配色（正文对比度 18.9:1），任何页面可切，
  答题中途切换不丢作答与滚动位置；选择记住，手机地址栏同步变黑。
- **两套题库各自独立**：进度、错题、收藏、笔记、历史按卷分开，互不覆盖。题号 T 卷显示 `#12`、S 卷 `S#12`。
- **模拟考试（官方卷面）**：60 单选 + 10 多选 + 40 判断 = 110 题，90 分钟，
  配分 1 / 2 / 0.5 分，满分 100 分；题目按比例从两套题库抽。
- **练习模式**：选完立即判对错，答对自动下一题，答错停留显示正确答案、解析与出题依据。
- **考试模式**：按题量给时间（54 秒/题兜底），可标记、跳题，交卷后逐题回顾。
- **答题卡**：已答 / 未答 / 标记 / 有笔记一目了然，点格子直接跳题；跳题栏支持 `#12` / `S12` 前缀。
- **关键词搜题**：答题页输入题干/选项/知识点关键词，命中题可直接跳转或组成专项练习。
- **错题本 / 收藏 / 笔记**：答错自动收录、答对自动移出；逐题笔记自动保存，可打印成清单。
- **统计**：按题型、按知识点、按题库看正确率，最近 7 天趋势图。
- **断点续做**：关掉再开会显示「继续：模拟考试 · 第 1/110 题」，限时与配分口径一并恢复。
- **自定义组卷**：按题号或范围（`1-50`、`120`、`165-171`）只练这些题。
- **答案管理**：按卷粘贴「题号 答案」覆盖，历史成绩自动按新答案重算。
- 适配手机（320px 无横向滚动），支持键盘 1–9 / A–H 选项、← → 切题。

## 答案说明

- 官方题库答案取自题库 PDF 原文的【答案】标注（2026-10-30 收录），未做改动；
  解析、知识点同样来自原文。
- 预测题库答案由命题规则推导，每题在页面上标出「依据」；与官方 1445 题做过全量查重
  （3-gram Jaccard，最高相似度 33.3%）与答案口径比对，无重复题、无实质冲突。
- 若后续拿到官方更正，在页面「答案管理」选对应题库，按 `题号 答案`（如 `1 D`、`S12 ACD`）
  粘贴覆盖，成绩会立即重算。
